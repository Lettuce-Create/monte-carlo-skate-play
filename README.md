# Monte Carlo Skate

The playable build of Monte Carlo Skate, the roller-rink card game, on Fortune Engine 2.0.

Play: https://lettuce-create.github.io/monte-carlo-skate-play/

This repo holds only the built game. The source is in the private Lettuce-Create/Games repo
(`monte-carlo/`); publish with `monte-carlo/tools/publish_play.sh`.
